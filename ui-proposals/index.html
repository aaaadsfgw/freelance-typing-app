C ベース + A の返信感

タイピング対象・売上・残り時間・コンボは C のまま大きく保ちます。 クライアント名・アイコン・案件名と、依頼のチャット吹き出し、返信中であることが分かる入力領域だけを A から足します。 入力文の重複はしません。

案 A · 一部採用

チャット没入型

狙い: 業務チャットの中で返信している感覚。

  • 長所: 会話感が最も強い。返信欄と入力が自然。
  • 短所: 売上や時間は端に寄る。ゲーム感は控えめ。
  • タイピング: 対象文は大きいが、チャットと入力欄で二重。
  • 仕事感: クライアントと話している感じが強い。
  • ゲーム性: HUD が小さい。
  • 発展: 複数スレッドや既読演出を足しやすい。
  • ローマ字: いま打つ音だけ表示。

管理画面型

狙い: 案件を回しているフリーランス SaaS 感。

  • 長所: 売上・時間・案件が一覧できる。仕事を回す感覚。
  • 短所: 情報量が多く、タイピングへの視線移動が起きやすい。
  • タイピング: 専用カードはあるが、画面の主人公ではない。
  • 仕事感: 案件管理している感じが最も強い。
  • ゲーム性: KPI カードで数字は見えるが、爽快感は中程度。
  • 発展: キュー、ステータス、クライアント一覧を足しやすい。
  • ローマ字: 全文を常時小さめ表示。

ゲーム性重視型

狙い: 稼いだ額とコンボが見える爽快感。

  • 長所: 売上・時間・コンボが瞬間で分かる。入力文が最大。
  • 短所: チャット没入感は弱い。案件の文脈は一段小さくなる。
  • タイピング: 3 案で最も読みやすい。
  • 仕事感: 世界観は残るが、ゲーム画面に近い。
  • ゲーム性: 報酬加算とコンボが最も目立つ。
  • 発展: コンボ演出やスコア演出を足しやすい。
  • ローマ字: ON / OFF トグルの見た目。
