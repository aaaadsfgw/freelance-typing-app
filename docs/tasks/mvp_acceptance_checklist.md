# MVP Acceptance Checklist

仕様: [docs/specs/mvp.md](../specs/mvp.md)  
UI: C ベース + A の返信感（`ui-proposals/game-c.html`）

## リポジトリと環境

- [x] GitHub リポジトリ `aaaadsfgw/freelance-typing-app` が public
- [x] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [x] D1 migration が Git 管理されている
- [x] ローカル D1 と本番 D1 が分離されている（`--local` / `--remote`）
- [x] 問題データを投入できる（`just db-seed`）

## 画面

- [x] タイトル: タイトル・説明・難易度選択・開始・分析導線
- [x] 難易度 3 種（初級 / 中級 / 上級）で開始できる
- [x] ゲーム: クライアント名・アイコン・案件名・依頼（チャット風）・返信入力が 1 箇所
- [x] タイピング対象が中央で最も大きい（重複表示なし）
- [x] 入力済み / 現在文字 / 未入力 / ミスが分かる
- [x] 残り時間・今月の売上・コンボ・完了案件数が見える
- [x] 結果: 売上・速度・正確性・ミス・最大コンボ・完了数・平均報酬・ランク/一言
- [x] 結果から再挑戦・難易度変更・分析へ進める
- [x] 分析: 苦手キー / 指 / キー遷移が見える

## ゲーム

- [x] ローマ字入力で日本語返信ができる
- [x] shi/si, chi/ti, tsu/tu, fu/hu などが通る
- [x] 誤入力で進まず、ミスとコンボリセットになる
- [x] 返信完了で報酬が加算され、次の案件へ自動で進む
- [x] 90 秒で結果画面になる
- [x] 問題が D1 から取得される

## データ

- [x] 終了時にプレイ結果が保存される（キーイベントの逐次送信なし）
- [x] 匿名 ID で同一ブラウザの履歴が分かる
- [x] 個人情報を保存しない

## 品質と公開

- [x] `just check` が成功する（lint / typecheck / test / build）
- [x] ローカルで一通りプレイできる（API・画面 200、問題取得・結果保存を確認）
- [ ] Cloudflare Workers にデプロイ済み
- [ ] 公開 URL から主要機能にアクセスできる
